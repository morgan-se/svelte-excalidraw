# SVEX

**SVEX** (**SV**elte **EX**calidraw) is a full-featured whiteboard app built on [svelte-excalidraw](/). Collaborative whiteboards with three storage modes: local folder, ephemeral rooms, and persistent workspaces.

- **Try it at [svex.tips.dev](https://svex.tips.dev)**
- [Self-hosting](/svex/self-hosting): Docker, [config](/svex/self-hosting/config), [storage](/svex/self-hosting/storage)

## What is SVEX?

### Local folder

Pick a folder on your computer. Each whiteboard is a file. Server stores nothing; data flows through it. Available at [svex.tips.dev](https://svex.tips.dev).

### Ephemeral room

Create a temporary room, share the link. Expires after a period of inactivity. Available at [svex.tips.dev](https://svex.tips.dev).

### Persistent workspace

Named workspace with a custom URL. Boards don't expire. [Self-host](/svex/self-hosting) only.
