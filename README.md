# svelte-excalidraw

![banner](/README.excalidraw.svg)

Svelte wrapper for [Excalidraw](https://github.com/excalidraw/excalidraw), virtual whiteboard with multiplayer.

**Docs:** [svelte-excalidraw.tips.dev](https://svelte-excalidraw.tips.dev)

**Try it:** [svex.tips.dev](https://svex.tips.dev)

---

| Package / App | Description |
| --- | --- |
| `packages/svelte-excalidraw` | Library |
| `apps/docs` | Docs site |
| `apps/svex` | Whiteboard app |

```bash
npm install
npm run dev:lib    # watch library
npm run dev:docs   # docs
npm run dev:svex   # svex app
```
